# Factory reference (Layer 3)

Stable across runs. Load only the file a stage Inputs table names.

| File | What it is | Load when |
|------|------------|-----------|
| `design-system.md` | Margin, type, cards, footer, colour tokens | Customize, build, review |
| `voice.md` | How page copy should sound | Intake copy, customize, review |
| `page-catalog.md` | Default running order and slugs | Intake, customize |
| `../config.example.yaml` | Generator keys and comments | Customize, build |

Do not put per-family names or a specific year in these files. Those belong in stage output.
